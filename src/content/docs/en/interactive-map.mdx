# Interactive map

Maps let you locate systems, teams or data centers and complement the diagrams of the
[C4 model](/docs/c4-model). The component loads lazily: MapLibre is only downloaded when a
page includes a map.

## Embedded example

<InteractiveMap
  center={[-3.7, 40.42]}
  markers={[
    { label: 'Madrid', coordinates: [-3.7, 40.42] },
    { label: 'Barcelona', coordinates: [2.17, 41.39] },
    { label: 'Lisboa', coordinates: [-9.14, 38.72] },
  ]}
  zoom={4}
/>

## How to use it

- `center`: initial `[longitude, latitude]` coordinates.
- `zoom`: zoom level (0–20).
- `markers`: list of `{ label, coordinates }`; each marker opens a popup with its label.

<Callout tone="tip" title="Light/dark theme">
  The map switches style automatically with the site's global theme, and its tiles are free
  (OpenFreeMap on OpenStreetMap data).
</Callout>
