# Getting started

This guide orients you in the site: how it is organized, in which order to read the
resources, and how to create your first MDX page if you contribute to the project. Each
page combines prose, highlighted code, Mermaid diagrams and embedded components, in two
languages and with integrated search.

## Recommended path

1. Read the [SOLID principles](/docs/solid) to sharpen your design vocabulary.
2. Learn to communicate architecture with the [C4 model](/docs/c4-model#levels).
3. Polish your code with the [clean code](/docs/clean-code) ideas.

## Highlighted code

```ts title="example.ts"
export function createArchitecture(name: string): string {
  return `Architecture: ${name}`;
}
```
